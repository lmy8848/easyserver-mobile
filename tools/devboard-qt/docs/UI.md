# DevBoard Qt · UI 设计规范（v1.0）

> 配套 `PLAN.md` ｜ 交互与布局的唯一规范来源 ｜ 实现以本文为准

> **实现现状（2026-10-27）**：主窗口是 Qt Widgets（`QMainWindow` + `QToolBar` + `QSplitter` + `QTabWidget`），不是 QML。镜像区是嵌入的 `scrcpy.exe` 子窗口，鼠标点击/滑动/多点、滚轮、键盘都直接由 scrcpy 处理，因此下文的自定义悬停工具条、镜像区导航键、坐标映射均未实现（这些能力由 scrcpy 自身提供）。
>
> 已实现：DeviceBar（设备下拉 / 刷新 / 连接设备 / 连接镜像 / 断开 / 无线配对 / 设置）、第二行按键栏（返回 / 主页 / 多任务 / 音量− / 音量+ / 电源 / 旋转）、右侧五 Tab（终端 / 日志 / 设备 / 操作 / 应用日志）、状态栏（重连与执行进度）、F1–F5 切面板、F6 启停 logcat、F7 清空日志、F8 刷新设备信息、F9 列出应用、F10 截图、F11 录屏（再按停止）、F12 打开保存目录、`Ctrl+,` 打开设置。应用日志落盘到 `%APPDATA%/DevBoard/DevBoard/logs`（按天轮转、保留 7 天）并实时显示在「应用日志」面板。

---

## 1. 设计原则

1. **镜像即主角**：视频区默认占据全部可用空间，工具面板默认收起
2. **零打扰**：所有控件可自动隐藏；状态信息进状态栏，不弹窗
3. **键盘优先**：全功能可用快捷键完成（对齐 scrcpy 习惯）
4. **状态可观测**：fps/延迟/码率常驻状态栏，异常态（掉线/降级）用大卡片明示原因
5. **布局记忆**：窗口尺寸、分栏比例、面板 Tab、上次设备全部持久化（QSettings）

## 3. MirrorView（核心交互）

### 3.1 显示
- 等比 letterbox，黑边使用窗口背景色（非纯黑，避免误判黑屏）
- 顶部不叠加任何常驻 UI；工具条悬停显示

### 3.2 悬停工具条（HoverToolbar）
- 触发：鼠标进入镜像区；**3s 无操作淡出**；按住 MOD 键时常显
- 内容：返回 / 主页 / 多任务 / 音量+− / 旋转 / 截图 / 录屏(30s) / 全屏
- 位置：镜像区底部居中，半透明圆角胶囊，不遮挡关键区域

### 3.3 输入
| 输入 | 行为 |
|---|---|
| 左键点按 | INJECT_TOUCH_EVENT DOWN+UP |
| 左键拖拽 | DOWN + MOVE* + UP（60Hz 采样，MOVE 合并） |
| 滚轮 | INJECT_SCROLL_EVENT（±1 格/刻度） |
| 右键 | BACK |
| 中键 | HOME |
| 物理键盘 | 直输文本（INJECT_TEXT）；MOD+b/h/s → 返回/主页/多任务 |
| 双击 | 进入/退出全屏（仅镜像区） |

### 3.4 降级态（SnapshotView / 断连）
- 断连：镜像区居中大卡片「连接已断开 · 原因 · [重连] [切换抓帧]」，不清屏不白屏
- 降级抓帧：同布局渲染单帧图，顶部黄色条「抓帧模式 · 1s」+ [回到实时] 按钮（可点，失败自动退回）
- 息屏：唤醒设备并在卡片提示「设备息屏，已自动唤醒」

## 4. SidePanels（右侧工具区，QTabWidget）

| Tab | 关键交互 |
|---|---|
| 终端 | 交互式 adb shell；↑↓ 历史；Ctrl+L 清屏；输出自动滚动（手动上滚即暂停，回底部恢复） |
| 日志 | logcat 流式；等级色标；关键字过滤 + 仅 E/W 开关；手动上滚暂停自动滚动；暂停/恢复/清空 |
| 设备 | 键值信息表（可复制）；5s 自动刷新 + 手动刷新 |
| 操作 | APK 路径（拖拽 .apk 到窗口即安装）/ 卸载包名 / 截图保存 / 录屏 30s / 重启应用 |
| 设置 | 外观、应用锁、保持亮屏、码率/帧率/max-size、解码器（软/硬）、MOD 键选择 |

- 每个 Tab 独立 keep-alive（切换不丢状态）
- 拖拽 .apk 到窗口任意位置 = 安装（全局 drop 事件）

## 5. DeviceBar（顶部）

- 左：设备下拉（QComboBox，显示 `型号 · 状态 · 连接方式`），当前设备高亮
- 中：连接详情（serial + 无线/USB 图标）
- 右：[配对向导] [手动连接] [设置] [⟳]
- 设备掉线：chip 变灰 + 状态栏提示；ConnectionWatcher 3s 轮询自动重连上次目标，成功后 toast「已恢复连接」

第二行「按键栏」：返回 / 主页 / 多任务 / 音量− / 音量+ / 电源 / 旋转，全部走 `adb shell input keyevent`（旋转走 `settings put system user_rotation`），与镜像设备一致（使用当前镜像的 serial，而不是下拉框里临时选中的设备）。

### 5.1 设置对话框（`Ctrl+,`）

四个分组，保存后才写盘：

- 镜像：分辨率上限（原始 / 1080 / 720 / 480）、帧率上限（不限 / 30 / 60 / 90）、码率上限（0 = 默认，最大 50 Mbps）、保持唤醒、连接后关屏。镜像参数在下次连接生效，改动会写进 scrcpy 启动参数。
- 连接：自动连接上次设备、重连次数（0 = 不自动重连）、重连间隔（1–60 秒）。
- 工具与文件：adb / scrcpy 可执行文件路径（留空走自动探测）、截图与录屏保存目录、应用日志目录（只读 + 打开）。
- 界面：字号 10–18px、窗口缩放时同步调整镜像。设置窗口几何也会在关闭时保存、下次启动恢复。

## 6. StatusBar（底部）

`●在线 · 无线 · H.264 60fps · 延迟 82ms · 码率 8.2Mbps · 1080x2400 · 软解 · CPU 12%`

- fps/码率：从视频帧 pts 每 2s 滑动窗口统计
- 延迟：可选校准（手机秒表法），未校准时显示「—」不造假
- 点击各段可复制

## 7. 快捷键

当前实现（Qt Widgets 壳）：

| 键 | 动作 |
|---|---|
| F1 / F2 / F3 / F4 / F5 | 切换右侧面板：终端 / 日志 / 设备 / 操作 / 应用日志 |
| F6 | 开始 / 停止抓取 logcat |
| F7 | 清空 logcat 输出 |
| F8 | 刷新设备信息 |
| F9 | 列出第三方应用 |
| F10 | 截图 |
| F11 | 录屏 / 提前停止录屏 |
| F12 | 打开截图与录屏保存目录 |
| Ctrl+, | 打开设置对话框 |

镜像区内的鼠标、键盘、滚轮由嵌入的 scrcpy 窗口直接处理，因此 scrcpy 自身快捷键（Alt+h 主页、Alt+b 返回等）在镜像区可用。旋转已通过工具栏「旋转」按钮提供（等价于规划中的 MOD+r）。

规划（未实现）：MOD+o 息屏、全屏、Ctrl+L 聚焦过滤框。

## 8. 视觉规范

- 主题：**深色为默认**（开发者工具惯例），可切浅色/跟随系统
- 强调色：Indigo #3949AB（与 App 品牌一致）；成功 #43A047；警告 #FB8C00；错误 #E53935
- 字体：UI 用系统默认（Segoe UI）；终端/日志用 Cascadia Mono / Consolas 11px
- 间距：8pt 网格；卡片圆角 8px；无边框悬浮元素用半透明胶囊
- 图标：Material Symbols（与移动端 App 一致）

## 9. 状态机（UI 视角）

```
Disconnected ──connect──▶ Starting ──首帧──▶ Mirroring
     ▲                        │失败              │
     │                        ▼                 ├─掉线─▶ Reconnecting ──成功──▶ Mirroring
     └──────────────────── Reconnecting ◀──────┘        │
                          （3s 轮询，状态栏+卡片提示）    └─用户切抓帧─▶ SnapshotMode
```

- 每个状态在镜像区/状态栏都有明确视觉表达；Reconnecting 显示已等待秒数
- 用户主动「切抓帧」不算降级：状态栏显示「抓帧模式」而非错误
